Instrukcja do zasumulowania środowiska z klastrem

1. Tworzenie oddzielnego kontenera z baza danych MySQL
docker run -d   --name admin-mysql_db   --network admin-mysql_default   -p 3306:3306   -e MYSQL_ROOT_PASSWORD=student mysql:5.7.41

2. Zbudowanie obrazu ze sklepem
docker build -t x0j3m/be_197933_pancernik .

3. Uruchomienie kontenera ze sklepem
docker compose up -d

4. Odczekać 20-30 sekund

5. Sklep: https://localhost:19793/
   Admin: https://localhost:19793/admin1234
